# Release readiness

<!-- sflow-copilot-pause -->
First run `singularity-flow phase enter --compose --for-agent --json` once; it composes context only when admitted. Lookup from current cwd (non-Git allowed). Never search `/Users`, `$HOME` or parents for a repo. Require returned `ready`/`workId`/`repositoryPath`; unavailable: `/sf-session` or `/sf-workspaces`, stop. It checks pause before Git. If `paused`, native Copilot; only offer `/sf-pause off`, never resume implicitly. Otherwise follow `agentGuide.readOrder` once, reuse binding/recovery/clarification/references and delivered inputs; no duplicate lookups. Read `clarification.checkpoint`: missing answers permit questions, not drafting. Missing record is not unanswered: reuse same-binding replies; repair recording. Never ask users to supply questions or slice control instructions. Use `personalization.replyName` literally in replies, never artifacts or approval identity.

<!-- sflow-output-contract: clarification-and-artifact -->
**Output contract:** Author configured artifacts from governed inputs and pinned clarification; publish only after readiness. Summarize artifacts with verified Markdown-preview links; never paste document bodies, code or diffs into Copilot. For code, list touched paths and observed added/deleted/created line counts; unavailable stays unavailable. Use existing evidence, not extra calls solely for display. Summaries, links and opened previews are not human review or approval. For every next action, honor returned `commandGuidance` in order: Copilot, Shell, VS Code (model-free) using `modelFreeCommand`; if absent, say "not available for this action". Missing Copilot: "no verified equivalent". Never invent routes. On a refusal read `remediationPlan`: run its first read-only step once and follow `context.strategy`; never retry an unchanged condition or edit an earlier phase to clear it. One returned `automatic` plan-hash action (such as `sync`) may run once, then re-enter once. Run a check only when a returned field or command asks for it; never decide from a step's name, kind or route that it applies. A refusal saying a check does not apply to this step is not a blocker: skip it and continue. A command's JSON is complete even when long: if your tool saved it to a file, read that file to its end before acting; never treat a saved or long result as truncated or stop because of its size.
<!-- sflow-execution-boundary -->
**Boundary:** reuse entry `ready`/`workId`, valid `phaseAgent`; cwd=`repositoryPath`. Honor `mutationContract`. Returned `workItemRoot`/artifact paths only; never `$HOME`.
Blocked: relay `resolution.issues[].choices` too. Eligible risk needs reason/expiry and authorized human confirmation. Never auto-accept risk.

1. Use entry `authoring`. If `policyVerified` is false, show `policyReason`; stop. Continue only if `effectiveAuthoringSkill` is `/sf-release`, or `/sf-phase` with `authoringSkill` null and `<phase>` = `release`; else relay its verified route; null drafts nothing. `retained-generation`: relay `next`, stop.
2. Review entry `recovery` and exact diffs; stop for protected/unowned edits or required human decisions. `successor-preparation-required`: run `successor.preparation.command`, preserve private drafts/publications and refresh entry once. Use entry `context.text` and available release/operations/security grounding; if `not-requested` or stale, rerun it once with `<phase> --work-id <WORK-ID> --compose`. Not admitted: relay blockers/next, stop. Never infer `--task`.
3. Reuse inputs/references and `retainedExecutionEvidence`; reconcile stale prose/IDE discovery with bound governed results, never turn command success into criterion acceptance or rewrite approved reports. Expand only missing material. Follow `clarification.checkpoint`: off skips; reuse replies, record unanswered questions before preparation. Repair recording, not questions.
4. Preparation is not authoring. Run `singularity-flow prepare <phase>` unless prepared in step 2; use the native file-edit tool to complete the existing release report and every artifact-set member, including Agent brief. Resolve template TODOs and preserve managed blocks. When the step declares a `verification/` member, bind the approved Verification generation, exact paths/hashes, observed results, and gaps in its `evidence-index.md`; otherwise list evidence gaps. Never invent evidence.
5. Cover deployment/preconditions, migrations/flags, validation/metrics/alerts, success, rollback, communication, ownership and escalation.
6. Run `singularity-flow phase prepublish <phase> --for-agent --json --publish-if-ready` (includes draft-check). Unready: reuse findings/resolution; fresh diagnostics only when requested by its next action. Stay in this phase. Correct agent findings from governed evidence only when `correction.sameTurn`; else route to owner/regenerator. Never blindly delete markers, invent facts/padding, nest models or overwrite producers. Follow returned `repairLoop.protocol`; stop unchanged.
7. Use returned `commands.publish` when `ready` unless `publishIfReady.published`; absent: relay `commands.next`, stop. Race-time `ARTIFACT_AUTHORING_INCOMPLETE`: recheck once, retry once if ready, never loop. Never submit or approve.
8. From `publishIfReady.review`, summarize the published documents with verified Markdown-preview links, generation/hashes, warnings and current `reviewBinding`. Never reproduce bodies or count a summary/link as human review; document reuse never carries approval consent.
9. Never submit/approve. Relay each `handoff`: `Next in Copilot: /sf-…` from `copilotCommand`, then `Terminal equivalent: singularity-flow …` from `command`.
