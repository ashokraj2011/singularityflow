# Review source coverage

<!-- sflow-copilot-pause -->
Review: first run `singularity-flow review-source context --for-agent --json` once in every turn, also after an interrupted one: an earlier turn's packet is context, not this turn's binding. It checks pause before Git and returns exact review material. Explicit `stage`/`check`/`submit`/`status`/`decide`: reuse this invocation's verified entry, otherwise run `singularity-flow session current --for-agent --json` once. If `paused`, native Copilot; only `/sf-pause off`, never resume implicitly. Use `personalization.replyName` once per reply/suggestion group, never artifacts or approval identity. Lookup from current cwd (non-Git allowed). Never search `/Users`, `$HOME` or parents for a repo. Require returned `ready`/`workId`/`repositoryPath`; unavailable: `/sf-session` or `/sf-workspaces`, stop.

<!-- sflow-output-contract: governed-review -->
**Output contract:** Show the exact reviewed hashes, cited gaps, exclusions, questions, and test exceptions before any human approval. Summarize artifacts with verified Markdown-preview links; never paste document bodies, code or diffs into Copilot. For code, list touched paths and observed added/deleted/created line counts; unavailable stays unavailable. Use existing evidence, not extra calls solely for display. Summaries, links and opened previews are not human review or approval. For every next action, honor returned `commandGuidance` in order: Copilot, Shell, VS Code (model-free) using `modelFreeCommand`; if absent, say "not available for this action". Missing Copilot: "no verified equivalent". Never invent routes. Run a check only when a returned field or command asks for it; never decide from a step's name, kind or route that it applies. A refusal saying a check does not apply to this step is not a blocker: skip it and continue. Act on a result's `act` first: its state, `do` routes and any `ask`. A bounded result names `agentOutput.read` ranges and `omittedFields` text files; read all in one response with your file tool. If your host saved a result to a file you cannot open, run that command again with `--for-agent --json`; never read the host's copy with shell tools.
<!-- sflow-execution-boundary -->
**Boundary:** reuse this invocation's review entry: require `ready`/`workId`, valid `phaseAgent`; cwd=`repositoryPath`. Use returned `workItemRoot`/artifact and Git-private staging paths; never `$HOME`. Use exact CLI-returned paths. `repositoryPath` is command cwd, not a prefix for absolute file paths. Never rebase paths or strip `.git/worktrees`. Issued private/external files are exact exceptions to repository confinement, not wider read/write permission; writes still need authorization. Resolve relative paths only against their declared base. On failure, preserve the path and error; never search or recreate it.

Explicit `stage`/`check`/`submit`: relay once. `status`: read. Legacy `decide`: retain phase/finding/reason; hand off to `/sf-review-decide` in a new turn. Never confirm/decide as reviewer. Unknown: help, stop.

Read pinned `clarifications`/`clarificationGuidance`; acknowledge `clarificationsReviewed` IDs and phase/generation/question. Never re-ask settled answers. Deferred answers waive nothing. Correct mistaken reviews in this generation; real gaps need successors.

1. Read `reviewGuide.readOrder`; no inventory rescans. Include explicit phase initially. `canReview: false`: relay `continuation.actions`, stop; only the author prepares/publishes successors. A missing original is restored through its returned route, never by recreating the Story. Require published `reportTemplate.binding`, `kind: specification|planning`. Unavailable/truncated sources: name their IDs and stop; route to `/sf-documents`. Inspect `visualSources` with native image/PDF tools; fill `visualSourcesReviewed` with actual method, page/region and observations. Cite them via row attestation, never invented text lines. No suitable tool: ask for help or a text export. `unreadableSources` need human `unreadable:<DOC-id>` decisions (step 5), never quotes.
2. Follow `reviewer.effectiveInstructions` when supplied, otherwise `reviewer.instructions`; no agent setup/selection. Retain as `requiredReviewerAgentId`, preserving author. `blocked-author-conflict`: relay `recovery.actions`. Compare authored-content hashes. Never edit sources, artifacts, tests, workflow, approvals or history.
3. Fill `reportTemplate` against `reportSchema`; preserve binding/metadata. `citationGuide`: source text-file lines, not JSON; exact single-line quotes. Map all scenarios/clauses, including clarified ones; real gaps need blocking findings. Attest only unreadable and inspected visual sources. Planning: singular `clauseId`, exact `expectedPaths`/`plannedTests`; test-only needs no product paths. Replace `unreviewed` honestly. Findings: `id`, `severity`, `message`. Never mark a real gap supported merely to pass validation.
4. Use `stagingProtocol`: file-edit tool at its exact path; terminal-only: `kernelStage` with shell-quoted JSON. Native file-read; no shell writers/parsers, mkdir, pipes/chains. Run `singularity-flow review-source check <phase> --report-file <that-path> --json` standalone. Apply `repair` citation/mapping hints now, at most two changed-packet repair attempts; never unchanged retries. If `retentionReady` is false afterward, stop without commit/push; list remaining fields. Otherwise retain once with `stagingProtocol.retain`, including honest gaps; correction-required is not retention failure or approval. Tool-form refusal: correct form, not judgments.
5. Only `pendingDispositions` allow `/sf-review-decide <phase> --finding <ID> --reason <TEXT>` in a separate human turn; never decide as reviewer. End with `continuation.actions`, target generation/owner; absent: `singularity-flow review-source status <phase> --json`. Never waive, publish, advance or acknowledge amendments for the person.
