# Generate the active phase

<!-- sflow-copilot-pause -->
First run `singularity-flow phase enter --compose --for-agent --json` once; it composes context only when admitted. Lookup from current cwd (non-Git allowed). Never search `/Users`, `$HOME` or parents for a repo. Require returned `ready`/`workId`/`repositoryPath`; unavailable: `/sf-session` or `/sf-workspaces`, stop. It checks pause before Git. If `paused`, native Copilot; only offer `/sf-pause off`, never resume implicitly. Otherwise follow `agentGuide.readOrder` once, reuse binding/recovery/clarification/references and delivered inputs; no duplicate lookups. Read `clarification.checkpoint`: missing answers permit questions, not drafting. Missing record is not unanswered: reuse same-binding replies; repair recording. Never ask users to supply questions or slice control instructions. Use `personalization.replyName` literally in replies, never artifacts or approval identity.

<!-- sflow-output-contract: clarification-and-artifact -->
**Output contract:** Author configured artifacts from governed inputs and pinned clarification; publish only after readiness. Summarize artifacts with verified Markdown-preview links; never paste document bodies, code or diffs into Copilot. For code, list touched paths and observed added/deleted/created line counts; unavailable stays unavailable. Use existing evidence, not extra calls solely for display. Summaries, links and opened previews are not human review or approval. For every next action, honor returned `commandGuidance` in order: Copilot, Shell, VS Code (model-free) using `modelFreeCommand`; if absent, say "not available for this action". Missing Copilot: "no verified equivalent". Never invent routes. On a refusal read `remediationPlan`: run its first read-only step once and follow `context.strategy`; never retry an unchanged condition or edit an earlier phase to clear it. One returned `automatic` plan-hash action (such as `sync`) may run once, then re-enter once. Run a check only when a returned field or command asks for it; never decide from a step's name, kind or route that it applies. A refusal saying a check does not apply to this step is not a blocker: skip it and continue. A command's JSON is complete even when long: if your tool saved it to a file, read that file to its end before acting; never treat a saved or long result as truncated or stop because of its size.
<!-- sflow-execution-boundary -->
**Boundary:** reuse entry `ready`/`workId`, valid `phaseAgent`; cwd=`repositoryPath`. Honor `mutationContract`. Returned `workItemRoot`/artifact paths only; never `$HOME`.
Blocked: relay `resolution.issues[].choices` too. Eligible risk needs reason/expiry and authorized human confirmation. Never auto-accept risk.

1. Use entry `authoring`; false `policyVerified`: show `policyReason`, stop. If `effectiveAuthoringSkill` is not `/sf-phase`, relay it and `Terminal equivalent: singularity-flow prepare <phase>`, stop; null drafts nothing. `retained-generation`: relay `next`, stop.
2. Review diffs. `contextAdmission.pendingEvidence`: preserve files/index, repair verified drafts, review contracts before publication. Otherwise stop for human/protected/unowned edits. `successor-preparation-required`: run `successor.preparation.command`; preserve private drafts/publications, refresh entry once. No implicit successors or loops.
3. Use entry `context.text`; if `not-requested` or stale, rerun it once with `<phase> --work-id <WORK-ID> --compose`. `not-admitted`: relay blockers/next, stop; no retries or inferred `--task`. Unavailable World Model: zero grounding bytes, not an authoring ban.
4. Follow `clarification.checkpoint`; off skips. Reuse same-binding human replies; ask only unanswered/changed questions with `ask_user` (unavailable: show them and stop). File-edit `{"responses":[...]}` at `clarification.responseStagingPath`, run `checkpoint.recordAction` alone. On refusal preserve replies/staging; repair recording, not questions. Remove staging only on success; record before preparation. Staging is JSON only, never handwritten governed records.
5. Run `singularity-flow prepare <phase>` unless prepared in step 2 or `authoringProgress.draft.draftExists`. Preparation is not authoring. Native file-edit tool: use `context.text`/`retainedExecutionEvidence`, reconcile stale prose/IDE discovery; finish artifact/Agent brief/TODOs, preserve drafts/managed blocks/approvals. Deterministic: regenerator only.
6. Preserve REQ/AC IDs; `/sf-code` owns tags. Retained files: `evidence` fulfillment, primary visual/inspection contracts. Review `planningEvidenceRepair` when `sameTurn`; recheck.
7. Prepublish rechecks recovery; never accept draft holds.
8. Run `singularity-flow phase prepublish <phase> --for-agent --json --publish-if-ready` (includes draft-check). Correct every agent finding under `correction.class`/`sameTurn`; route others to their owner, code to `/sf-code`. Never invent, pad, blindly delete markers, nest models or overwrite producers. Follow returned `repairLoop.protocol`; stop unchanged.
9. Ready and `publishIfReady.published` false: use returned `commands.publish`; advisories create no hold (`requiredBefore: approve` is later scope review). Absent: relay `commands.next`, stop. `ARTIFACT_AUTHORING_INCOMPLETE`: recheck/retry once if ready. Keep sanitized `telemetry/<phase>-gen<N>.json`. Never submit/approve.
10. From `publishIfReady.review`, report commit/push, model/cost, hash-bound documents/stage. Relay `handoff`'s `copilotCommand`/`command`. Not submission/review readiness.
