# Exact source review through the engine

The namespace engine exposes `source-review.context`, `source-review.record` and
`source-review.decide`. They use the pinned phase responsibilities, rather than specification or
planning names. The context issues exact document-read operations for the original Story,
publication-bound supporting inputs, artifact, human answers and independently approved scope.
A retained review is an independent semantic report, not phase approval or proof that prose is
correct. Citation, completeness, source, clarification and plan-row checks share the native rules.

The original native review implementation was captured before extraction at `4c36b3275`.
Thirty-seven fixed cases preserve returned values, report hashes, missing/future schema handling,
errors and disposition behavior. The pure reducer yields its existing plan-value timestamp
requests; the native wrapper retains the original clock checkpoint. Native review commands,
records, authority and CLI wording are unchanged.

Only the configured read-only review agent can record a report, and it must differ from the
published author. This is the single permitted retained-evidence mutation for that role; it grants
no source-edit, submission, human-decision or approval authority. Actual conditional receipts bind
the authenticated actor, original source/artifact hashes, report and operation identity. A lost
reply resumes its original prepared time and result. A different ID cannot duplicate an already
retained report. A corrected report can replace a mistaken review within the same generation;
genuine artifact defects still require the ordinary author repair/successor route.

Human exclusions, unreadable-source attestations and non-test dispositions need a separate exact
human decision. Its candidate digest binds the current report and pending item. It cannot waive a
reviewer's blocking defect or approve a phase. Configured person-presence still requires its actual
owner. A normal human Git or namespace identity is not fabricated as a presence receipt.

New submissions that require review use a distinct immutable packet v4. It retains the exact
accepted report and human-decision references. Publication still precedes source review. Approval
and takeover reconstruct the review from its original submission basis, including actual upstream
approval and report bytes. Old packet v1–v3 and publication meanings are unchanged. The report has
its own readable resource; guidance moves from review to submission once the real report is ready. Citation and acknowledgment
repairs stay with the reviewer; an explicit semantic blocker routes the actual author to a
successor. The native continuation snapshots retain their original bytes.

Uploaded supporting documents remain in the explicit device-local store. Their original bytes are
never copied into shared evidence. Another laptop needs matching input bytes before reading,
recording or revalidating a review that depends on them. Missing input, permission and timeout
errors retain their identities. Exact source citations in the authored report are retained with
the report. Multiple approved scope artifacts need their separate planning-review contract; this
profile refuses that missing owner instead of dropping sources.

Mac qualification includes all three shared backends, genuine independent phase approval,
custom planning-phase names, retained human answers, local attachment restore, interrupted
preparation, semantic-review correction and an actual offline-installed consumer with an empty
PATH. NodeNext checks require the report, phase, candidate digest and operation identity.
Qualification passes 288 distinct affected Mac checks with zero failures, cancellations or skips.
The unchanged 34-check installed-package qualifier runs alone in 33.1 seconds within its original
120/60-second limits. Source validation passes 4,166 checks; schema (6), architecture (92), VS Code
types, the 2,011-site Git ownership audit and all 13 original bundle ceilings pass. The gateway
contains 851 of 852 permitted modules. Native guide and next-step CLI/SDK parity also pass.
