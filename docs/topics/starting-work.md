Three intake doors, one result: `sflow start PAY-1234 --jira` (fetches the ticket), `sflow story start --story-file ./story.md` (local, IDs minted — no Jira required), or stories released from an epic breakdown. Starting pins the configuration, creates the canonical branch from the latest remote base, opens the first phase, and records the interval baseline. If the repository runs an impact study, enrollment confirms the complexity band before implementation so measurement stays honest.
