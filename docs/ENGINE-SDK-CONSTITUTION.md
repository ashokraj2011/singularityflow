# Constitution policy and namespace evidence

The kernel now owns standing-rule parsing, generated-article values, policy lookup, hashes,
citations, required-article selection and exception values. The optional `constitution` package
export receives explicit digest and YAML syntax primitives. It does not read a file, discover
Git, format a command, choose an identity or consult a clock. Generation returns a replacement
plan; the native adapter preserves the original YAML formatting and CLI hints.

The independent 47-case capture was recorded at `29475288f` before extraction. Native outputs,
generated Markdown, hashes and errors match it exactly. The pure missing-generated-block finding
omits the native shell command; that rendering remains in the adapter. Native exception records
keep their original fields and authority. Their shared schema declaration remains immutable v1.

Namespace Story creation validates the actual constitution in its approved configuration package.
The original namespace genesis shape is unchanged. A new publication carries a separately
versioned `constitution-policy/v1` proof and a readable report, bound to the exact source content,
configuration, artifact, original lifecycle basis and actor. The pin uses content references;
it does not fabricate Git commit fields. Historical publications retain their original profiles.

Enforce mode rejects missing required files, the native integrity findings and invalid citations.
Warn mode retains those disclosures. Structural/parser failures and genuine storage/permission
errors keep their real identities. Citation repairs use the current private draft and do not
regenerate an already valid upstream phase. The phase review packet includes the actual report,
including every evidence-required article. Human judgment is the real independently authorized
phase approval; the report explicitly says it has not performed that judgment.

The packaged Node host bundles the locked YAML parser's ESM syntax implementation. Its source
closure is explicitly limited to `node_modules/yaml/browser/`; there are no runtime npm dependencies
or new discovery/process capabilities. The parser's ISC notice is retained in
`dist/third-party/yaml-LICENSE` and covered by the build inventory. Ordinary native hosts continue
using their existing YAML binding and formatter.

Filesystem, SQLite and application-store journeys cover publication, submission, shared-only
independent approval, same-generation citation repair, warn mode, missing content, actual EACCES
and a lost publication acknowledgement. A separate empty-PATH, offline-installed consumer replays
the actual approved constitution and completes independent approval without a Git or CLI import.

Namespace article exceptions remain a separate human-decision owner; this proof does not grant an
exception, waive machine policy or represent automatic semantic acceptance. The Phase 5 and 7
completion ledger remains authoritative for that and the other remaining work.
