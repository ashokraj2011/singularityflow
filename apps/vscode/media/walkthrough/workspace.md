# Select or create a workspace

A workspace is a local directory plus governed capabilities and the repositories
those capabilities deliver from. Selecting one refreshes this window; it does not
open another VS Code instance. Expand it to inspect its directory, repository
health, Jira routing, metadata, and world-model status. Use its details page to edit
the display name or capability selection.

The CLI workspace registry remains the source of truth.
