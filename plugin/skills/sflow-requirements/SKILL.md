<!-- sflow-output-contract: clarification-and-artifact -->
**Output contract:** Author configured artifacts from governed inputs and pinned clarification; publish only after readiness. Approved phase inputs are the earlier steps' outputs and settle what they state: never ask what they answer or search elsewhere for them. Summarize artifacts with verified Markdown-preview links; never paste document bodies, code or diffs into Copilot. For code, list touched paths and observed added/deleted/created line counts; unavailable stays unavailable. Use existing evidence, not extra calls solely for display. Summaries, links and opened previews are not human review or approval. After a blank line, display each next action as three separate Markdown bullets, in order: "- Copilot: `<copilotCommand>`", "- Shell: `<command>`", "- VS Code (model-free): `<modelFreeCommand>`". Preserve exact returned routes; never combine them on one line or in a table. Missing Copilot: "no verified equivalent"; missing Shell or model-free: "not available for this action". Never invent routes or make further calls for formatting. On a refusal read `remediationPlan`: run its first read-only step once and follow `context.strategy`; never retry an unchanged condition or edit an earlier phase to clear it. One returned `automatic` plan-hash action (such as `sync`) may run once, then re-enter once. When a result's `act.state` is `author`, or it routes back to this skill with nothing for a person to answer, edit, review or confirm, that is this turn's own work: do it, never relay it. Copy every line a patch matches, changed or unchanged, from the file as it is now, read after your last edit of it, never from memory, a finding or a search result; one file per patch, so one stale hunk cannot reject the others. A file edit that does not match is not a refusal: read those lines again and redo the edit. Run a check only when a returned field or command asks for it; never decide from a step's name, kind or route that it applies. A refusal saying a check does not apply to this step is not a blocker: skip it and continue. Act on a result's `act` first: its state, `do` routes and any `ask`. View each `agentOutput.read` range and `need` text file in one response at its exact issued path in `.sflow/out/`, unless this chat already read that path (same path, same bytes); other `omittedFields` are optional. A cut-off, empty, running or inaccessible host result uses `singularity-flow result last --wait --for-agent --json`, never a command replay or shell read of the host's copy. Recover read-size/range failures with returned `readRequests`/`readRanges` in your file-view tool's parameters; finish all required ranges and continue this task. Use exact `pathCorrections`; never guess paths. Real missing-file/permission errors retain their path, native error and owner recovery route; never recreate inputs or retry unchanged access. Read `taskResume` on entry: keep its operation ID, spent budgets and exact next step across chats; obtain fresh context and local paths. Before ending, honor `taskCompletion`: input reads, preparation and diagnostic tests alone do not complete authoring or review. Preserve human decisions and explicit single-step boundaries.
<!-- sflow-execution-boundary -->
**Boundary:** reuse entry `ready`/`workId`, valid `phaseAgent`; cwd=`repositoryPath`, or as is from a non-Git (chat) folder: SFlow finds the bound checkout; never refuse or wrap for it. Honor `mutationContract`. Returned `workItemRoot`/artifact paths only; never `$HOME`. Use exact CLI-returned paths. `repositoryPath` is command cwd, not a prefix for absolute file paths. Never rebase paths or strip `.git/worktrees`. Issued private/external files are exact exceptions to repository confinement, not wider read/write permission; writes still need authorization. Resolve relative paths only against their declared base. On failure, preserve the path and error; never search or recreate it.
Blocked: relay `resolution.issues[].choices` too. Eligible risk needs reason/expiry and authorized human confirmation. Never auto-accept risk.

1. Use entry `authoring`. If `policyVerified` is false, show `policyReason`, offer `/sf-validate` then `/sf-recover`; stop. Continue only if `effectiveAuthoringSkill` is `/sf-requirements`, or `/sf-phase` with `authoringSkill` null and `<phase>` = `requirements`; else relay its verified route; null drafts nothing. `retained-generation`: relay `next`, stop.
2. Run `singularity-flow documents list`; view relevant inputs before deciding what is unclear.
3. Review recovery/diffs; stop for protected/unowned edits or human decisions. `successor-preparation-required`: run `successor.preparation.command`, preserve drafts/publications, refresh entry once. Use entry `context.text`/reference paths; if `not-requested` or stale, rerun it once with `<phase> --work-id <WORK-ID> --compose`. Not admitted: relay blockers/next, stop. Never infer `--task`; expand only needed missing/truncated inputs.
4. Follow entry `clarification.checkpoint`; off skips. Reuse actual same-binding replies; ask only unanswered/materially changed questions with `ask_user`, then record before preparation. Unavailable: show questions and stop; stage chat replies. Confirm outcome/scope/acceptance. File-edit only the issued staging path; run `checkpoint.recordAction` alone. On refusal preserve replies and repair recording, not questions.
5. Preparation is not authoring. Run `singularity-flow prepare <phase>` unless prepared in step 3; use its returned path and `source.json`. Use the native file-edit tool to complete the existing artifact from `context.text` and approved evidence, including Agent brief; resolve template TODOs, preserve managed blocks, never invent or pad.
6. Inspect only grounding-selected files. Do not implement code.
7. Cover problem, outcome, scope, measurable acceptance criteria with stable qualified `[WORK-ID:AC-001]` anchors (the work ID in capitals), dependencies, assumptions, risks, confirmed decisions, and deferred questions. Never use a bare `AC-001` as the authoritative clause ID.
8. Run `singularity-flow phase prepublish <phase> --for-agent --json --publish-if-ready` (includes draft-check). Unready: reuse findings/resolution; fresh diagnostics only when requested by its next action. Stay in this phase. Correct agent findings from governed evidence only when `correction.sameTurn`; else route to owner/regenerator via `correction.guidance`/`correction.skill`. Never blindly delete markers, invent facts/padding, nest models or overwrite producers. Follow `repairContinuation`/`repairLoop.protocol`; no unchanged retries or resets. Respect `correction.maximumChangedFingerprints`; exhausted: preserve work and return manual/owner routes.
9. Use returned `commands.publish` when `ready` unless `publishIfReady.published`; absent: relay `commands.next`, stop. Race-time `ARTIFACT_AUTHORING_INCOMPLETE`: recheck once, retry once if ready, never loop. Never submit or approve.
10. From `artifacts`, summarize the published documents with verified Markdown-preview links, hashes and warnings. Never reproduce bodies or count a summary/link as human review; document reuse never carries approval consent.
11. Report decisions, tokens, and commit. End with each returned `handoff`: `Next in Copilot: /sf-…` from its `copilotCommand`, then `Terminal equivalent: singularity-flow …` from its `command`; do not submit or approve.
