# Your local profile

Set your display name and menu persona so the extension can put the most relevant
navigation first. It never hides commands, grants approval authority, or selects a governed agent. The
workflow phase selects a governed agent; the real Git/GitHub identity is recorded
for lifecycle decisions.

The **New workspace** form asks for this profile during workspace creation and
reuses the answer here and in Configuration Center. It is stored only in your
machine's VS Code settings; it is not written to `workspace.json` or a repository.

Available personas include Product owner, Architect, Developer, QA, Admin, and
supporting delivery roles. You can switch at any time from the persona button in
the Navigator header. Favorites you explicitly customize are preserved.

[Configure profile](command:singularityFlow.configureProfile)
