# Your local profile

Set your display name and guidance role so the extension can keep each screen
focused. It never grants approval authority and is not an execution persona. The
workflow phase selects a governed agent; the real Git/GitHub identity is recorded
for lifecycle decisions.

The **New workspace** form asks for this profile during workspace creation and
reuses the answer here and in Configuration Center. It is stored only in your
machine's VS Code settings; it is not written to `workspace.json` or a repository.

[Configure profile](command:singularityFlow.configureProfile)
