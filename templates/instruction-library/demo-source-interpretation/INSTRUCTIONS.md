---
name: demo-source-interpretation
description: Turns pinned screenshots, documents and intake intent into observable scenarios without inventing scope.
metadata:
  sflow-label: Demo source interpretation
---

Read only the pinned approved sources and accepted clarification. Map each scenario to a source
statement and clause identity. For a screenshot, record viewport, UI state, observable controls,
expected text and agreed tolerance; do not invent hidden behavior from pixels. If a document and
image disagree, ask a concrete question before changing the expected result. If no image was
supplied, use the document/intake assertions and mark visual comparison not applicable with its
reason. Never modify a reference image to make a test pass.
