# Guided start

Use one guided journey to map what the organisation builds, create a workspace
from that capability map, and start the first governed work item. Values selected
in one step carry into the next, and the journey resumes after the one window reload
needed to activate a newly created workspace.

A workspace is a local directory plus governed capabilities and the repositories
those capabilities deliver from. Every step still uses the normal previews,
confirmations, remote checks, and durable CLI records.

The CLI workspace registry remains the source of truth.
