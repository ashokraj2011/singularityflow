# Review your own work

Go through the change line by line and answer each question honestly:

1. Does it do exactly what the plan said, and nothing it did not?
2. Is every new behaviour covered by a test that ran and passed?
3. Would a reader understand each changed function without asking you? Add a short doc comment
   where they would not.
4. Did anything fail, get skipped, or look risky? Say so in the summary instead of hiding it.

Fix what you can now. List what is left, with why, for the person who approves the step.
