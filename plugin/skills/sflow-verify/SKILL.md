1. Run `singularity-flow nextsteps --for-agent --json` for any workflow. Stop at recovery, pending publication, approval, completion or cancellation. `<phase>` is its Boundary phase, whatever it is named.
2. Require Boundary `ready` and exact `phaseAgent`; otherwise relay the nextsteps route and stop. Run `singularity-flow phase show <phase> --for-agent --json`. If `policyVerified` is false, show `policyReason`, offer `/sf-validate` then `/sf-recover`; stop. If `effectiveAuthoringSkill` is not `/sf-phase` (a release step returns `/sf-release`), relay it and stop. Keep Story context governed.
3. Run `singularity-flow phase enter <phase> --compose --for-agent --json`; use `context.text` and `retainedExecutionEvidence`. Never derive `--task` from Story text.
4. Read the approved phase inputs and changed source.
5. Map each AC to evidence and qualified `@ac:WORK-ID:AC-001` in an executable test. Inspect source-bound `@clause:WORK-ID:REQ-001` as a trace witness, not a verdict. Reject bare `AC-001`; honor reviewed test-only/non-code exemptions.
6. Use bound runs over stale prose; cite a run reused on this tree as any other, never as missing. IDE discovery is not execution. Honor runner ownership; no substitute commands. Command success is not criterion acceptance. Source edits need governed repair/fresh evidence.
7. Cover relevant regression, boundaries, failures, security, accessibility/performance.
8. Preparation is not authoring. Run `singularity-flow prepare <phase>`; use the native file-edit tool to complete the existing artifact with observed evidence and `Agent brief`: verdict, failures/omissions, risk, release recommendation. Resolve TODOs, preserve managed blocks. Failed/unavailable tests are not passes but a verdict to write; never invent results.
9. Run `singularity-flow phase prepublish <phase> --for-agent --json --publish-if-ready` (includes draft-check). Unready: run read-only `singularity-flow recover <WORK-ID> --phase <phase> --for-agent --json`. Correct every agent finding now; route other producers to owner via `correction.guidance`/`correction.skill`. Never blindly delete markers, invent facts or padding, nest models or overwrite producers. Follow `repairContinuation`/`repairLoop.protocol`; no unchanged retries or resets; same findings after a change: correct differently. Exhausted `correction.maximumChangedFingerprints`: preserve work, return manual/owner routes.
10. Use returned `commands.publish` when `ready` unless `publishIfReady.published`; absent: relay `commands.next`, stop. Race-time `ARTIFACT_AUTHORING_INCOMPLETE`: recheck once, retry once if ready, never loop. Never submit or approve.
11. From `artifacts` and `publishIfReady.review.testEvidence`, summarize tests, gaps, publication, verified Markdown-preview links and hashes. No bodies/code/diffs; summaries/links are not human review or reusable approval consent.
12. Never submit/approve. End with each `handoff` from step 11: `Next in Copilot: /sf-…` from its `copilotCommand`, then `Terminal equivalent: singularity-flow …` from its `command`.
