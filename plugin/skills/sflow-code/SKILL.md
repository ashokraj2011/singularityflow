# Governed code

<!-- sflow-copilot-pause -->
First run `singularity-flow phase enter --for-agent --json` once. Lookup from current cwd (non-Git allowed). Never search `/Users`, `$HOME` or parents for a repo. Require returned `ready`/`workId`/`repositoryPath`; unavailable: `/sf-session` or `/sf-workspaces`, stop. It checks pause before Git. If `paused`, native Copilot; only offer `/sf-pause off`, never resume implicitly. Otherwise follow `agentGuide.readOrder` once, reuse binding/recovery/clarification/references and delivered inputs; no duplicate lookups. Read `clarification.checkpoint`: missing answers permit questions, not drafting. Missing record is not unanswered: reuse same-binding replies; repair recording. Never ask users to supply questions or slice control instructions. Use `personalization.replyName` literally in replies, never artifacts or approval identity.

<!-- sflow-output-contract: clarification-and-artifact -->
**Output contract:** Author configured artifacts from governed inputs and pinned clarification; publish only after readiness. Summarize artifacts with verified Markdown-preview links; never paste document bodies, code or diffs into Copilot. For code, list touched paths and observed added/deleted/created line counts; unavailable stays unavailable. Use existing evidence, not extra calls solely for display. Summaries, links and opened previews are not human review or approval. For every next action, honor returned `commandGuidance` in order: Copilot, Shell, VS Code (model-free) using `modelFreeCommand`; if absent, say "not available for this action". Missing Copilot: "no verified equivalent". Never invent routes. On a refusal read `remediationPlan`: run its first read-only step once and follow `context.strategy`; never retry an unchanged condition or edit an earlier phase to clear it. One returned `automatic` plan-hash action (such as `sync`) may run once, then re-enter once.
<!-- sflow-execution-boundary -->
**Boundary:** reuse entry `ready`/`workId`, valid `phaseAgent`; cwd=`repositoryPath`. Honor `mutationContract`. Returned `workItemRoot`/artifact paths only; never `$HOME`.
Blocked: relay `resolution.issues[].choices` too. Eligible risk needs reason/expiry and authorized human confirmation. Never auto-accept risk.

1. Require entry `phase`, `phaseAgent.valid: true`, `generatesCode: true`, `authoring.policyVerified`; relay other routes, never draft sign-off. Read `mutationContract`/`authoringProgress`: binding is not source permission; kernel-only `/sf-next` cannot inline authoring.
2. Review `recovery`, `intent`, test handoff and exact diffs/untracked bytes including `workflow.json`. Pending evidence: preserve files/index, repair draft; never accept evidence. Otherwise stop on protected/unrelated/unowned edits or lifecycle/authority blockers. Repair owned open-intent actions; runner repair requires `CODE_DELIVERY_TEST_COMMAND_REQUIRED`. Untracked `.sflow/results/**` need no cleaning; review tracked/staged reports. Consumed-changed intent needs reviewed rollover; unchanged publication: relay `next`, stop. Require open intent; absent: `singularity-flow phase begin <phase> --json` with adoption/confirmation before edits/composition; never auto-adopt. Successful begin: refresh entry once. Consumed intent requires `/sf-recover`.
3. Compose once: `singularity-flow phase enter <phase> --work-id <WORK-ID> --compose --for-agent --json`; use `context.text`. `not-admitted`: relay blockers/next, stop.
4. Follow `clarification.checkpoint`; off skips. Reuse same-binding human replies; ask only unanswered/changed questions with `ask_user` (unavailable: show them and stop). File-edit `{"responses":[...]}` at `clarification.responseStagingPath`; run `checkpoint.recordAction` alone. On refusal preserve replies/staging; repair recording, not questions. Remove staging only on success; record before code mutation; refresh entry once. Staging is JSON only, never handwritten governed records.
5. Verify references; refuse invalid/dirty. `singularity-flow revision status --json` only when `generation > 0`. Source edits require `codeAuthoringReady: true`, context/clarification. Preserve code/tests; prepare missing artifact via `authoringProgress`. Preparation is not authoring.
6. Native file-edit tool: finish behavior/tests/artifact/Agent brief. Repair missing summary/planned bindings in this draft. Planned App.test.jsx cannot be replaced by utility tests; verify assertions, never fabricate tags. Preserve managed blocks. Doc-comment APIs; tags are not docs. Exclude fixtures/docs/deletions/symlinks. Product: `// @clause:ORDER:REQ-001 rationale` (`REQ|BEH|IFC|AC|CON`); tests: `// @ac:ORDER:AC-001` above the test. Honor pinned test-only opt-outs.
7. Follow `testExecution.handoff`; `argvWithheld: true` means configured, not missing. No adoption/amendment for redaction/inference or reporter flags. Publication runs fresh tests, no pre-run. Unavailable runner: returned recovery. No skip/list/dry-run/no-tests. Authorized dependencies only; never edit protected config, disable hooks or fabricate results.
8. Run `singularity-flow phase prepublish <phase> --for-agent --json` (includes draft-check). Follow `correction.class`/`sameTurn`, `traceabilityRepair.actions`; verify assertions/hashes, repair tags without per-tag consent. Never invent, pad, delete markers, nest models or overwrite producers. `ready` is not test success. Follow `repairLoop.protocol`; stop unchanged.
9. Use returned `commands.publish` once when ready; successful required tests continue publication. Advisories create no hold; `requiredBefore: approve` is later accounting. Absent: relay `commands.next`, stop. Refusal: report command ID, argv/cwd, exit, bounded stderr/guidance. Nonzero exit fails despite passing JUnit. `/sf-recover`: proven runtime repair permits retry without source changes; consumed edits need rollover. `ARTIFACT_AUTHORING_INCOMPLETE`: recheck/retry once. Never submit/approve.
10. `singularity-flow phase show <phase> --for-agent --json`: viewing only. Finish summary/traceability/prepublish/publication. Blocked: exact repairs/routes. Published: handoff, not /sf-code again.

TRP: `singularity-flow explain test-recovery`.
