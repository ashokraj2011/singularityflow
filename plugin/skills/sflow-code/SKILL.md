# Governed code

<!-- sflow-copilot-pause -->
First run `singularity-flow phase enter --for-agent --json` once. Lookup from current cwd (non-Git allowed). Never search `/Users`, `$HOME` or parents for a repo. Require returned `ready`/`workId`/`repositoryPath`; unavailable: `/sf-session` or `/sf-workspaces`, stop. It checks pause before Git. If `paused`, native Copilot; only offer `/sf-pause off`, never resume implicitly. Otherwise follow `agentGuide.readOrder` once, reuse binding/recovery/clarification/references and delivered inputs; no duplicate lookups. Read `clarification.checkpoint`: missing answers permit questions, not drafting. Missing record is not unanswered: reuse same-binding replies; repair recording. Never ask users to supply questions or slice control instructions. Use `personalization.replyName` literally in replies, never artifacts or approval identity.

<!-- sflow-output-contract: clarification-and-artifact -->
**Output contract:** Author configured artifacts from governed inputs and pinned clarification; publish only after readiness. Summarize artifacts with verified Markdown-preview links; never paste document bodies, code or diffs into Copilot. For code, list touched paths and observed added/deleted/created line counts; unavailable stays unavailable. Use existing evidence, not extra calls solely for display. Summaries, links and opened previews are not human review or approval. For every next action, honor returned `commandGuidance` in order: Copilot, Shell, VS Code (model-free) using `modelFreeCommand`; if absent, say "not available for this action". Missing Copilot: "no verified equivalent". Never invent routes.
<!-- sflow-execution-boundary -->
**Boundary:** reuse entry `ready`/`workId`, valid `phaseAgent`; cwd=`repositoryPath`. Honor `mutationContract`. Returned `workItemRoot`/artifact paths only; never `$HOME`.
Blocked: relay `resolution.issues[].choices` too. Eligible risk needs reason/expiry and authorized human confirmation. Never auto-accept risk.

1. Require entry `phase`, `phaseAgent.valid: true`, `generatesCode: true`, `authoring.policyVerified`; relay other routes, never draft sign-off.
2. Review `recovery`, `intent`, test handoff and exact diffs/untracked bytes including `workflow.json`. `contextAdmission.pendingEvidence`: preserve held files/index; continue verified draft repairs, never accept evidence; contract review precedes publication. Otherwise stop on protected/unrelated/unowned edits or lifecycle/authority blockers. Repair owned open-intent actions; runner repair requires `CODE_DELIVERY_TEST_COMMAND_REQUIRED`. Untracked `.sflow/results/**` need no cleaning; review tracked/staged reports. Consumed-changed intent needs reviewed rollover; unchanged publication: relay `next`, stop.
3. Run `singularity-flow phase enter <phase> --work-id <WORK-ID> --compose --for-agent --json` once. Use `context.text`. `contextComposition: not-admitted`: relay `contextAdmission.blockers`/`next`, stop; no blind retries. Never infer `--task`.
4. Follow `clarification.checkpoint`; off skips. Reuse same-binding human replies; ask only unanswered/changed questions with `ask_user` (unavailable: show them and stop). File-edit `{"responses":[...]}` at `clarification.responseStagingPath`, run `checkpoint.recordAction` alone. On refusal preserve replies/staging; repair recording, not questions. Remove staging only on success; record before code mutation, never promises. Clarification staging is JSON only; never handwrite governed records.
5. Use verified `references.repositories[].localPath`; refuse invalid/dirty. `singularity-flow revision status --json` only when `generation > 0`. Require open intent; absent: `singularity-flow phase begin <phase> --json` with adoption/confirmation. Consumed intent requires `/sf-recover`.
6. Use native file-edit tool: implement code/tests, author artifact/Agent brief from real evidence; preparation is not authoring. Preserve managed blocks. Doc-comment APIs; tags are not docs. Exclude fixtures/docs/deletions/symlinks. Planned product paths: `// @clause:ORDER:REQ-001 rationale` (`REQ|BEH|IFC|AC|CON`); executable tests: `// @ac:ORDER:AC-001` above its test. Honor pinned test-only opt-outs.
7. `testExecution.handoff`: ready/withheld argv is configured; no adoption/amendment or package-script edit for reporter flags. Publication/submission run fresh tests; no pre-run. Unavailable runner: returned recovery/adoption. No skip/list/dry-run/no-tests. Authorized dependencies only; never edit protected config, disable hooks or fabricate results.
8. Run `singularity-flow phase prepublish <phase> --for-agent --json` (includes draft-check). Obey `correction.class`/`sameTurn`, `traceabilityRepair.actions`: verify behavior/assertions/hashes, repair owned tags without per-tag confirmation. Implement gaps, clarify ambiguity; publication runs fresh tests. Repair every agent finding now; never invent, pad, blindly delete markers, nest models or overwrite producers. `ready` is not test success. Follow returned `repairLoop.protocol`; stop unchanged.
9. Use returned `commands.publish` once when `ready`; passing required tests continue publication. Advisories/API-doc notices create no hold; report `requiredBefore: approve` as later scope accounting. Absent: relay `commands.next`, stop. Refusal: report `requiredTestExecution` ID, argv/cwd, exit, bounded stderr/guidance; hidden argv is not missing. Nonzero exit fails despite passing JUnit. Follow `/sf-recover`; proven runtime repair permits retry without source changes; consumed source edits need review/rollover. `ARTIFACT_AUTHORING_INCOMPLETE`: recheck once, retry once. Never submit/approve.
10. `singularity-flow phase show <phase> --for-agent --json`: viewing only; summarize hash-bound references/handoff and test/publication status. Binary/unavailable counts are not zero. No bodies, source snippets or diffs.

TRP: `singularity-flow explain test-recovery`.
